OBS Studio 推流配置 · THREE STEPS

01 · 安装 OBS Studio

从官网 obsproject.com 下载安装，谨防盗版。

02 · 配置推流

OBS 设置 → 直播 → 服务选择「自定义」，填入服务器地址与推流码：

[主站] 服务器 —（内地 / 海外通用）

[副站] 服务器 —（内地 / 海外通用）

推流码即主播资格卡中的整串（格式 房间号?token=15位串码），粘贴到 OBS「推流密钥」（仅审批通过后可见）。

03 · 开始直播

添加源 → 点击「开始直播」。观众在 直播间 输入你的房间号即可观看。
